 Вы можете искать объекты (организации, здания, достопримечательности, остановки транспорта, парковки и т. д.): 
 
 по текстовому запросу , 
 по типу объекта , 
 по ID объекта , 
 по ID категории , 
 по ID организации , 
 по ID бренда . 
 
 Для поиска организаций по стандартным параметрам (названию, адресу, категориям и другим) укажите параметр type=branch в запросе к endpoint-у /3.0/items . Также вы можете использовать endpoint-ы для поиска организаций по уникальным атрибутам. Доступ к ним (кроме /3.0/items/byservicing ) предоставляется по запросу и за дополнительную плату. Чтобы приобрести доступ, свяжитесь с отделом продаж 2ГИС : 
 
 /3.0/items/byservicing — поиск организаций, обслуживающих здание, по ID здания ; 
 /3.0/items/bysite — поиск организаций по сайту ; 
 /3.0/items/byphone — поиск организаций по номеру телефона ; 
 /3.0/items/byitin — поиск организаций по ИНН ; 
 /3.0/items/bytradelicense — поиск организаций по торговой лицензии ; 
 /3.0/items/byfias — поиск организаций по коду ФИАС . 
 
 По текстовому запросу ​ 
 Вы можете указать в параметре q текстовый запрос для поиска: объект, который нужно найти, например «метро», «кафе», «аптека» и другие. Можно уточнить запрос, указав: 
 
 определённое место ( Большой театр ) или название организации ( кафе «Шоколадница» ); 
 категорию ( магазины музыкальных инструментов ); 
 критерий ( рестораны с итальянской кухней ); 
 другие параметры. 
 
 В параметре q можно одновременно указать и объект, и геоограничение, например кафе в Тверском районе Москвы . В запросе можно указать только один параметр q . Если вы не укажете геоограничение в параметре q , для повышения точности поиска передайте его другими способами, например, с помощью параметров location , city_id , region_id и других. Полный список см. в инструкции Геоограничение поиска . 
 Чтобы найти объект, отправьте GET-запрос к /3.0/items со следующими параметрами: 
 
 q — текстовый запрос, например «новая третьяковка». 
 city_id — ID города, например city_id=4504222397630173 для Москвы. Подробнее о получении ID см. в разделе ID города . Вы можете указать геоограничение другим способом: подробнее см. в инструкции Геоограничение поиска . 
 
 Пример запроса: 
 https://catalog.api.2gis.com/3.0/items?q=новая третьяковка&city_id=4504222397630173&key=API_KEY

 По типу объекта ​ 
 С помощью параметра type вы можете искать объекты определённого типа: организации, здания, улицы, парковки, остановки, станции метро, достопримечательности и другие. 
 Параметр type можно указать для endpoint-ов: 
 
 /3.0/items , 
 /3.0/items/byfias . 
 
 Полный список типов объектов см. в справочнике API. 
 Чтобы найти объекты определённого типа, отправьте GET-запрос к /3.0/items со следующими параметрами: 
 
 q — текстовый запрос , например «метро». 
 point — координаты центра точки поиска в формате долгота,широта , например point=37.630866,55.752256 . 
 radius — радиус поиска в метрах, например radius=1000 . Вы можете указать геоограничение другим способом: подробнее см. в инструкции Геоограничение поиска . 
 type — тип объекта, например type=station.metro для поиска станций метро. 
 
 Пример запроса: 
 https://catalog.api.2gis.com/3.0/items?q=метро&point=37.630866,55.752256&radius=1000&type=station.metro&key=API_KEY

 По ID объекта ​ 
 Вы можете искать объекты по их уникальному идентификатору (ID). 
 Чтобы найти объект по его ID, отправьте GET-запрос к /3.0/items/byid с параметром id — ID объекта, например id=70000001080081802 . Подробнее о получении ID см. в инструкции Получение ID объектов . 
 Пример запроса: 
 https://catalog.api.2gis.com/3.0/items/byid?id=70000001080081802&key=API_KEY 
 Пример ответа: 
 response.json { "meta" : { "api_version" : "3.0.20949" , "code" : 200 , "issue_date" : "20260703" } , "result" : { "items" : [ { "address_name" : "Театральная площадь, 2" , "id" : "70000001080081802" , "name" : "Большой театр России, касса" , "type" : "branch" } ] , "total" : 1 } } 
 По ID категории ​ 
 С помощью параметра rubric_id вы можете получить список организаций определённой категории, например, только кафе или только продуктовые магазины. 
 Чтобы отфильтровать результаты поиска по ID категории организации, отправьте GET-запрос к /3.0/items со следующими параметрами: 
 
 q — текстовый запрос , например «кофе». 
 location — координаты точки поиска в формате долгота,широта , например location=37.630866,55.752256 . Вы можете указать геоограничение другим способом: подробнее см. в инструкции Геоограничение поиска . 
 rubric_id — ID категории, например rubric_id=161 для получения организаций в категории «кафе». Подробнее о получении ID см. в разделе ID категории . 
 
 Пример запроса: 
 https://catalog.api.2gis.com/3.0/items?q=кофе&location=37.630866,55.752256&rubric_id=161&key=API_KEY

 По ID организации ​ 
 С помощью параметра org_id вы можете получить список всех филиалов одной организации, например, только филиалы Почты России. ID организации различаются в зависимости от региона. 
 Чтобы отфильтровать результаты поиска по ID организации, отправьте GET-запрос к /3.0/items со следующими параметрами: 
 
 org_id — ID организации, например org_id=70000001087490185 . Подробнее о получении ID см. в разделе ID организации .

 Пример запроса: 
 https://catalog.api.2gis.com/3.0/items?org_id=70000001087490185&location=37.630866,55.752256&key=API_KEY

 Поиск организаций ​ 
 По ID здания ​ 
 Вы можете получить список организаций, обслуживающих здание: 
 
 Городских обслуживающих организаций: почта, поликлиника, ЖКХ. 
 Интернет-провайдеров. 
 
 Чтобы получить список организаций, обслуживающих здание, отправьте GET-запрос к /3.0/items/byservicing со следующими параметрами: 
 
 building_id — ID здания, например building_id=4504235282736775 . Подробнее о получении ID см. в разделе ID здания . 
 servicing_group — тип обслуживающей организации, например servicing_group=internet для поиска интернет-провайдеров. Полный список типов обслуживающих организаций см. в Справочнике API . 
 
 Пример запроса:
