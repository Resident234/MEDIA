 Как начать использовать API 
 API Поиска по организациям (API ППО) — это HTTP API, который позволяет находить организации по различным критериям: по названию, адресу, номеру телефона и др. 
 Обратите внимание, лицензии на продукт API Поиска по организациям следует приобретать совместно с лицензией на JavaScript API и Геокодер . Это связано с тем, что данные, полученные через API Поиска по организациям, должны быть всегда отображены на карте. Вы не можете получать данные поиска и не отображать их на карте. -->
 Тарифы 
 Для API Поиска по организациям доступна только стандартная лицензия. Расширенной лицензии для этого сервиса нет, так как запрещается сохранять или изменять данные, полученные от этого API. 
 Тариф определяет лимит запросов к сервису, включенных в минимальный платеж. Запросы все лимита оплачиваются отдельно и по предоплате. 
 Внимание 
 Обратите внимание, лицензия на продукт приобретается на год или на месяц. Внести оплату на другой срок нельзя. Кроме того, возможна только предоплата — вы сможете начать использовать API только после того, как внесете полный минимальный платеж.
